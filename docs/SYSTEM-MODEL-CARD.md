# Модель и данные

Модель: Qwen/Qwen2.5-7B-Instruct-AWQ, revision b25037543e9394b818fdfca67ab2a00ecc7dd641, лицензия Apache-2.0. Веса, tokenizer и hashes перечислены в models/qwen-manifest.json. Обучение и fine-tuning не выполняются. Serving: локальный vLLM 0.10.2, AWQ Marlin, контекст 4096 токенов.

Назначение: поиск разрешённых цитат и совместных упоминаний оборудования. Модель выбирает source IDs, сервер восстанавливает исходный текст, проверяет offsets и актуальные права. Пользователь сверяет документ и версию перед инженерным решением. Система не предназначена для автономного управления оборудованием.

Данные: синтетические русскоязычные технические документы и PDF-скан. Реальные документы предприятия и персональные данные не используются. Ошибочное число в источнике может быть точно процитировано; противоречия требуют проверки специалистом. OCR извлекает текст, геометрия чертежей и сложные таблицы не интерпретируются.

Проверки охватывают цитаты, ACL, tenant/session isolation и контекст. Синтетический набор не заменяет экспертную оценку на отраслевом корпусе. Квантование может влиять на качество; сравнение с неквантованной моделью не выполнено. Автоматическая LLM-as-a-Judge оценка отсутствует.

При ошибочном выборе источника или нехватке контекста используется явный extractive fallback. При отсутствии подтверждений возвращается no_evidence. Содержимое документов не передаётся во внешние inference API или облачную телеметрию.
