## Новые findings

**F06, P2, observability correctness.** На baseline после `http.response.start(status=200)` отмена ASGI task либо ошибка `send(body)` попадала в finally и учитывалась как `success`. Первопричина: outcome определялся только по последнему status, а факт завершения тела не отслеживался. Reproduction: `python tools/finalize_runtime.py independent --label <новое-имя>`; историческое RED — `baseline/independent/run.log` и JUnit: 9 PASS / 2 FAIL. Исправлены только transport outcomes; HTTP status_class сохраняет наблюдавшийся status, бизнес-результат остаётся отдельным. `cancelled`, `transport_error`, `incomplete`, `unexpected` имеют ограниченное множество значений. При обычном disconnect без исключения незавершённое тело учитывается как incomplete. Клиентские байты после send сервер доказать не может.

**F07, P2, CI artifact binding / permissions.** Исходный workflow после build монтировал checkout поверх `/app`, не сравнивая runtime bundle. Так можно проверить отличающиеся исходники вместо собранного image. Кроме того, app UID 10001 не гарантированно может писать в checkout runner UID; запись evidence зависела от прав host. Исходный YAML сохранён в `baseline/workflow-before.yml`. Изменение: отдельный runtime identity extraction + equality check, read-only source mount, отдельный evidence bind с UID runner, CPU evaluation на runtime image без перекрытия `/app`, upload evidence даже при failure. Удалённый GitHub Actions — NOT RUN, локальные эквивалентные стадии не являются доказательством remote success.

**Тестовый сбой, не дефект приложения.** В `candidate/final-tests/unit.log`: 50 PASS / 1 FAIL. Новый тест ошибочно считал, что `with sqlite3.connect(...)` закрывает свой raw connection. Этот context manager commit/rollback выполняет, но соединение оставляет открытым; именно тест удерживал WAL. Добавлен явный close тестового handle. Failed JUnit/coverage не удалены, исправленный набор публикуется под другим label.

**Ограничение model evidence, не новая уязвимость.** Основной повторяющийся вопрос на свежем corpus вызывает реальный Qwen, но проходит через `extractive-invalid-generation`. То же наблюдается на baseline и candidate, поэтому это не регрессия WAL. Primary output отбрасывается, canonical full units проходят прежние grounding и final ACL checks. Причина конкретного отклонения диагностируется отдельно без записи prompt/quote в numeric profile; результат — `candidate/generation-diagnostic.json`. Короткий real-generation case GPU regression остаётся `vllm`. Требования release gate не ослаблялись ради GO.

## Границы гарантии

BEGIN IMMEDIATE линеаризует SQL writers и snapshot выдачи. Committed SQL revoke до reservation наблюдается; более поздний writer ждёт transaction commit. Это не distributed revocation lease на весь интервал доставки. File identities перечитываются внутри boundary, но атомарный provisioning файла и корпоративный identity lifecycle остаются внешним контрактом; SQLite не блокирует файлового администратора.

Finalization revalidates tenant/grants/source version/text/title/page, session owner и graph provenance, пишет history и chained audit и фиксирует deep JSON snapshot. Генерация, client serialization и socket delivery не удерживают write transaction. Однопроцессный RLock и SQLite timeout не являются гарантией fairness/starvation freedom при произвольном числе внешних writers; stress/HA на производственном объёме не заявляется.

`verified_span` намеренно консервативен: сокращение или десятичная точка могут выглядеть как граница selection, но наружу всё равно возвращается весь canonical paragraph. NFKC может изменять OCR representation; offsets проверяются относительно сохранённого нормализованного текста, не координат исходного PDF. Знание истинности документа, корректности OCR и универсальное semantic entailment требуют других доказательств.

Все SQL/index/credential/failure операции выполнены в `course-final-20261020` с новыми synthetic identities и volumes. Веса смонтированы read-only. `portal_qdrant`, исходные volumes/индексы/корпоративные документы не изменялись. Tests не используют внешние inference API и не обходят ACL ради ускорения.
