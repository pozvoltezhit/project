| CPU extractive, in-process ASGI | 300 / 8 | 58,27 | 129,24 / 163,73 / 347,84 | 0 |
| HTTP gateway → backend → GPU, generic AWQ | 24 / 4 | 0,36 | 10 995,80 / 11 659,09 / 11 669,01 | 0 |
| HTTP gateway → backend → GPU, AWQ Marlin | 24 / 4 | 2,27 | 1675,28 / 1964,63 / 1972,34 | 0 |

Исходные JSON: `benchmark.json`, `benchmark-awq.json`, `benchmark-gpu.json`. GPU elapsed 66,721 с → 10,567 с. Прогоны измеряют полную задержку разрешённого ответа с проверкой exact quotes; streaming TTFT не измерялся, потому что SSE выпускает только завершённый проверенный результат. Установленный vLLM прямо рекомендовал совместимый Marlin вместо generic AWQ; baseline сохранён. Показанное ускорение около 6,31 раза по elapsed относится к этому стенду и workload.

Вход — одинаковый вопрос User B о связи Н-17 → К-2 → Д-8, три синтетических документа, тёплая модель и prefix cache. Нет случайного корпуса, широкого распределения длин, soak test, отказов оборудования и конкурентного ingestion. Поэтому это достигнутая скорость короткого контрольного прогона, а не максимальная capacity / production SLA. Цель p95 ≤5 с на этом сценарии выполнена только финальным kernel. CPU число не измеряет нейросетевую генерацию и не сравнивается с GPU как равнозначная нагрузка. Для sizing реального пилота нужны репрезентативный corpus, query mix, Golden Set и длинный ступенчатый load test.

```powershell
docker compose -p course-knowledge -f infra/compose.yaml -f infra/compose.indexes.yaml -f infra/compose.gpu.yaml up -d --build
docker compose -p course-knowledge -f infra/compose.yaml -f infra/compose.indexes.yaml -f infra/compose.gpu.yaml exec -T backend python -m backend.check
```

Дождаться окончания model loading и пробного успешного query. `/health` — liveness API, не readiness всей платформы. Для generic baseline заменить quantization на awq и повторить тот же workload. Не запускать одновременно стороннюю GPU-нагрузку.

## Ограничения и артефакты

Hash embeddings / lexical reranker проверены фактически; опциональный pretrained multilingual encoder не доставлен и не оценён. Канонический traversal выполняется в SQLite, Neo4j показывает производный граф. OCR подтверждён для русского текста image-only PDF; геометрия чертежей и сложные таблицы не объявлены распознанными. Regex guardrails не заменяют red teaming; exact quote validation и ACL являются независимыми слоями. Синтетический корпус не заменяет LLM-as-a-Judge / доменную оценку качества.

Vault, SSO, mTLS, DMZ, HA, backup restore и production certification остаются архитектурными controls ADD, а не выполненными развёртываниями MVP. Учебный стек и небольшой global lock имеют явные ceilings. Секреты в `data/` исключены из ZIP; перенос начинается с init_demo. Weights исключены из ZIP и уже находятся локально в `models/`; staging script и manifest включены. Записи экранов и журналы в `evidence/`, шестиминутный смонтированный deep dive в `демо.mp4`, текст озвучки в `демо-текст.md`.
